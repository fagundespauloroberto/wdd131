Nome do Projeto: Patinhas Conectadas 🐾

1. Visão Geral
O Patinhas Conectadas é uma plataforma digital desenvolvida para conectar tutores, protetores independentes e
ONGs de animais de estimação a potenciais adotantes. O objetivo principal é desburocratizar e acelerar o
processo de adoção, oferecendo uma interface intuitiva, filtros de busca eficientes e um canal direto de
comunicação entre quem doa e quem busca um novo membro para a família.

2. Objetivo do Projeto
Para os Doadores: Fornecer um painel de gerenciamento onde possam cadastrar seus pets, atualizar status
de adoção e organizar o histórico de cuidados.
Para os Adotantes: Facilitar a busca por animais através de critérios geográficos (cidade/estado), porte e
espécie, tornando o processo de triagem rápido e humanizado.
Impacto: Reduzir o número de animais abandonados por meio da visibilidade digital e centralização de
contatos.

3. Principais Funcionalidades
A. Módulo de Autenticação e Perfil
Cadastro de usuários (Doadores/ONGs).
Login seguro para gerenciamento dos perfis.
Gestão de dados de contato (WhatsApp integrado).
B. Módulo de Gestão de Animais
Cadastro Simplificado: Upload de fotos e inserção de características físicas (espécie, idade, porte, cor).
Storytelling: Campo de descrição detalhada para incentivar o vínculo emocional.
Controle de Status: Alternância entre Disponível, Reservado ou Adotado.
C. Módulo de Consulta (Busca Pública)
Listagem de Animais: Galeria visual com cards informativos.
Filtros Inteligentes: busca rápida por localização, espécie ou porte.
Botão "Quero Adotar": Link direto para o WhatsApp do responsável, removendo intermediários
desnecessários.

4. Estrutura de Dados
O sistema é composto por duas entidades centrais inter-relacionadas através de uma chave estrangeira:
4.1. Doador: Armazena dados de identidade (Nome, tipo de perfil, contato).
4.2. Animal: Armazena dados biográficos e técnicos do pet, sempre atrelado a um ID de Doador.

5. Justificativa Estratégica (Valor Agregado)
O projeto prioriza a experiência do usuário (UX) através de um design limpo, focado no aspecto emocional,
evitando regras de negócio desnecessárias para garantir um ciclo de vida ágil (da ideia ao desenvolvimento). É
um produto com alto apelo visual, sendo excelente para demonstrar competências de manipulação de banco de
dados, autenticação de usuários e tratamento de imagens em um portfólio profissional.
